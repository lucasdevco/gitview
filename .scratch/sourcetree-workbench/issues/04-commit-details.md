# 04: 提交详情与提交 diff

**What to build:** 在历史中选中一个提交，下方左侧上半部分显示它改动的文件列表，下半部分显示提交详情（主题、正文、完整哈希、父级、作者、日期、提交日期、标签），右侧显示所选文件在该提交中的 diff。点击父级跳转到父提交。工作区有改动时历史顶部出现“未提交的更改”行（作为父节点为 HEAD 的虚拟节点参与提交图布局），选中它显示工作区改动。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] `GET .../commits/{oid}` 返回正文与文件列表（`--name-status -z`），含重命名
- [ ] `GET .../diff` 支持 commit 来源，根提交与合并提交行为正确
- [ ] 合并提交无文件改动时显示明确说明；二进制与超大 diff 有提示
- [ ] 父级链接可点击跳转并滚动到父提交
- [ ] “未提交的更改”行与虚拟节点正确参与泳道布局（vitest 覆盖）
- [ ] API 测试覆盖普通提交、根提交、合并提交、重命名
