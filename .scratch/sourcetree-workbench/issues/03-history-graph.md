# 03: 历史视图与提交图

**What to build:** 点击“历史”，看到真实仓库的提交列表（图表、描述、提交 10 位哈希、作者含邮箱、日期“今天/昨天/完整日期”）和带颜色泳道的提交图；HEAD 用空心圆标出且描述加粗；提交前显示指向它的本地分支、远程分支、标签（按泳道着色、长名中间省略），落后上游的本地分支旁显示“落后 N 个版本”。侧边栏显示按 `/` 分层的分支树（当前分支加粗，领先/落后数）、标签、远端 origin 下的远程分支树，单击定位到对应提交。筛选栏支持所有分支/当前分支、显示/隐藏远程分支、跳转到。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `GET .../graph` 一次返回全部提交的 oid、parents、作者、邮箱、作者时间、提交时间、主题（`%x00` 分隔），支持所有分支/当前分支范围，不分页截断
- [ ] `GET .../refs` 用一次 `for-each-ref` 返回本地分支、远程分支、标签及上游与领先/落后，不逐分支调用 `rev-list`
- [ ] 前端泳道布局沿用原型的 `layoutGraph(nodes) → GraphRow[]` 数据形状，虚拟列表渲染，几万条提交滚动流畅，任何滚动位置泳道连续
- [ ] 分支树、标签、远端在侧边栏按原型呈现，单击定位并滚动到提交
- [ ] 筛选栏三个控件生效，“跳转到”可选任意分支
- [ ] 搜索视图按提交信息、作者、哈希前缀过滤
- [ ] vitest 覆盖泳道布局（分叉、合并、多父提交、泳道复用）、分支树构建、日期格式化
- [ ] API 测试覆盖含合并与多分支的临时仓库
